# 跨区域通道协同清障

把跨区域通道的区段、部门、资源要素和依赖记录整理成可计算的协同产品。
牵头单位不再面对月报里模糊的「推进中」，而是能下钻的堵点、风险传播链和综合效能。

## 领域资料

`contracts/context.schema.json` 定义共享资料格式，`fixtures/context.json` 提供可公开使用的虚构样例（澜临跨海通道）。`src/context.js` 的读取器拒绝结构问题（缺字段、悬空引用、环图、非法枚举）；承诺四要素缺失、证据不足等业务语义问题不拒识，交给分析器判定。

### 依赖图

节点类型覆盖通道协同的全部要素：

| 类型 | 含义 | 堵点类别 |
| --- | --- | --- |
| `section` | 通道区段 | 工程进度 |
| `permit` | 许可（`category`: land/sea/energy/ecology） | 用地/用海/用能/生态要求 |
| `standard` | 标准（`scope`: national/local，带版本） | 国家标准/地方标准 |
| `regulation` | 法规（带版本） | 法规要求 |
| `funding` | 资金 | 资金 |
| `precondition` | 施工前置 | 施工前置 |
| `facility` | 算力/数据设施 | 算力数据设施 |
| `network` | 配套网络 | 配套网络 |
| `resilience` | 韧性措施 | 韧性措施 |

边 `from → to` 表示「下游 `to` 依赖上游 `from`」。图必须无环。

### 业务规则

- **地方承诺**：责任人、截止日、依据、受影响节点四要素齐全才算有效；有效承诺逾期自动标记，受影响区段可追溯。
- **法规/标准变更**：登记换版后沿依赖图自动传播，给出到每个受影响节点的完整路径；生效日后的法规/标准节点视为符合新版。
- **计划谱系**：延期、替代路线、争议裁决、灾害重排都会替换计划，被替换方案连同替换原因完整保留。
- **完成声明**：区段「已完工」必须能下钻到自身前置许可的批复证据、工程验收和联调证明，缺一不可。
- **多方协同**：事件账本检出同字段并发写冲突（最后写入者胜出，被覆盖写入保留备查）；跨时区会议按参会人时区换算本地时间。
- **灾害与服务**：灾害影响沿依赖图传播，触发计划重排；服务中断/恢复台账统计中断时长并对照恢复目标。
- **敏感字段**：节点可声明 `sensitive_fields`，受限视图下自动脱敏。
- **区域汇总**：区域/通道级综合状态由区段推导，但逐条保留区段原始结论，不得抹去。

## 可计算指标

`src/metrics.js` 用五项分量合成综合效能（权重公开）：

- 依赖清零率（0.3）：区段前置要素完成占比
- 承诺可信度（0.2）：兑现=1、在途=0.5、逾期/违约=0
- 有据完工率（0.2）：证据链完整的完工区段占比
- 标准法规符合率（0.15）
- 服务可用率（0.15）

## 代码结构

```
src/context.js        读取器与结构校验
src/graph.js          依赖图、闭包、路径、生效状态、堵点类别
src/blockers.js       堵点计算与月报解释（「推进中」→ 根因链）
src/commitments.js    承诺四要素有效性与逾期
src/propagation.js    法规/标准变更传播
src/plans.js          计划谱系（延期/替代路线/裁决/重排）
src/evidence.js       完成声明的证据下钻
src/collaboration.js  并发冲突与跨时区会议
src/disaster.js       灾害影响传播与服务恢复
src/sensitivity.js    敏感字段脱敏
src/rollup.js         区域/通道汇总（保留原始结论）
src/metrics.js        可计算指标与综合效能
src/index.js          汇总入口 summarize()
```
